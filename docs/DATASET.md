# Dataset notes

Dataset: CIC-IDS2017 (Canadian Institute for Cybersecurity). The project specification cites Sharafaldin, Lashkari, and Ghorbani, “Toward Generating a New Intrusion Detection Dataset and Intrusion Traffic Characterization,” ICISSP 2018.

The dataset must be obtained manually from the official Canadian Institute for Cybersecurity source. Before redistribution or publication, verify and summarize the current official download page's citation and licence/terms here. No dataset files are included in this repository.
